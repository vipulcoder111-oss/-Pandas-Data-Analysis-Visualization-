# Pandas Data Analysis & Visualization

A Python-based data analysis and visualization project that uses **Pandas** to analyze CSV data and **Matplotlib** to create meaningful visualizations.

<br>

## 📌 Project Overview

This project demonstrates how Python can be used to load, explore, analyze, and visualize structured data stored in a CSV file.

<br>

The project performs basic statistical analysis and generates different visualizations to identify patterns, relationships, and insights within the dataset.

<br>

## 🚀 Features

- Load CSV data using Pandas <br>
- Display and explore dataset records <br>
- Generate basic statistical summaries <br>
- Calculate average values of selected columns <br>
- Analyze relationships between numerical variables <br>
- Create Bar Charts <br>
- Create Scatter Plots <br>
- Create Correlation Heatmaps <br>
- Identify patterns and trends in the dataset <br>
- Generate insights based on the analysis <br>

<br>

## 🛠️ Technologies Used

- **Python** <br>
- **Pandas** <br>
- **Matplotlib** <br>
- **CSV** <br>
